# Flask API and React app with MongoDB 

This is a simple React App and Flask API that uses MongoDB as its database.

## Running locally

```bash
cd app
npm install
npm run dev
```

```bash
cd api
pip install pipenv
pipenv shell
pipenv install
python run.py
```

### Using Docker

```bash
docker compose up
```
